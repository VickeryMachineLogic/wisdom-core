# Contributing to Wisdom Core

Thank you for being here. Wisdom Core is here to help people build better agents, and it is free for everyone to use, fork and build on.

## Use it, fork it, build on it

Wisdom Core is free and open source under the [MIT license](LICENSE). Use it in personal or commercial projects, change it, fork it and ship it. Just keep the copyright and license notice with it (it sits at the top of `wisdom_core.py`, so it travels with the file).

## Ideas, bug reports and questions are very welcome

The best way to help right now is to tell us what you found. Please [open an issue](https://github.com/VickeryMachineLogic/wisdom-core/issues). There are short templates for bugs and ideas, and a blank issue is fine for anything else, including questions. Hearing what confused you in the docs helps too.

For a bug, these help most:

- the version (`wisdom-core --version`) and your Python version,
- the model backend and model names (for example Ollama with `llama3.2` and `nomic-embed-text`),
- what you did, what you expected, and what happened instead (the error text, or report lines such as `! learning failed: ...`).

## Security problems

Please don't open a public issue. Report them privately through GitHub's [private vulnerability reporting](https://github.com/VickeryMachineLogic/wisdom-core/security/advisories/new). See [SECURITY.md](SECURITY.md).

## Code contributions

Wisdom Core is maintained by John Vickery at Vickery Machine Logic, who looks after every change to the project. Code contributions and pull requests aren't being accepted right now, so please share fixes and ideas as issues instead. A clear description of the problem and how to reproduce it is a real help. Trusted maintainers may be invited in the future.

Thank you for helping make Wisdom Core better.
