# Security Policy

## Supported versions

Wisdom Core is in alpha. Security fixes go into the latest release only.

## Reporting a vulnerability

Please do not report security problems in public issues.

Report them privately through GitHub's private vulnerability reporting: open the
[Security tab](https://github.com/VickeryMachineLogic/wisdom-core/security) of this
repository and choose **Report a vulnerability**
([direct link](https://github.com/VickeryMachineLogic/wisdom-core/security/advisories/new)).

Include what you found, how to reproduce it, and the version affected. We aim to
acknowledge reports within a few business days and will coordinate a fix and
disclosure through a GitHub security advisory.

Wisdom Core is maintained by Vickery Machine Logic, LLC.
